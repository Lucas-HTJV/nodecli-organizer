# NodeCLI Organizer 🚀

CLI em Node.js para organizar automaticamente arquivos da pasta Downloads.

## ✨ Funcionalidades
- Organização por tipo (Imagens, Vídeos, Documentos, etc)
- Suporte a `--dry-run`
- Caminhos inteligentes (Downloads, Documents, etc)
- CLI global via npm link

## 📦 Instalação
```bash
npm install -g nodecli-organizer
